# Review

대상: 기본 브랜치 대비 변경 + 작업 트리 변경

```bash
git diff --stat origin/main...HEAD; git status --short
```

## 체크리스트

**타입·품질**
- [ ] 새 `any`, `as unknown as`, `@ts-ignore`, `@ts-expect-error`, `eslint-disable`
- [ ] `console.log`, 주석 처리된 코드, 담당자 없는 TODO
- [ ] 300줄 넘는 컴포넌트, 같은 마크업 복붙

**범위**
- [ ] 요청서의 "범위 밖"이나 다른 사이트 파일이 바뀌었는가
- [ ] 프로필의 보호 경로가 바뀌었다면: 영향받는 곳과 팀 규칙에 따른 문서 갱신을 확인했는가

**보안**
- [ ] 하드코딩된 키·토큰·URL 비밀값, `NEXT_PUBLIC_` 로 노출된 비밀값
- [ ] 개인정보가 로그·fixture·스크린샷에 들어갔는가

**동작**
- [ ] 바뀐 로직에 테스트가 있는가 (UI 마크업만 바뀐 경우는 제외 가능)
- [ ] 이미지 `alt`, 버튼/링크 구분, 키보드 포커스, 제목 순서(h1→h2)
- [ ] Next.js: 불필요한 `'use client'`, `<img>` 대신 `next/image` 검토, 외부 링크 `rel`

## 보고

```
## 판정: 통과 / 수정 필요

### 수정 필요
- [파일:라인] 문제 — 이유 — 제안

### 확인하지 못한 것
```

근거가 약한 지적은 "선택 사항"으로 따로 구분한다.
